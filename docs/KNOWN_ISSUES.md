# 已知问题与局限

这份清单随版本更新。发现新问题请[提交 Issue](https://github.com/zhouxishun1993-code/keyoudu-exercise-dataset/issues/new/choose)。

## 没有专业审核

全部 1,296 个动作的文字和图片都没有经过专业教练或运动医学人员审核。图片由 AI 生成，文字由 AI 整理、翻译或改写。

## 图片

- **ex-0308 哑铃平板飞鸟**：结束图里两侧手臂不对称，一侧明显屈肘收在身前，不是标准的双侧飞鸟。文字说明按标准动作写，以文字为准。
- **ex-0596 器械坐姿夹胸**：图中器械带前臂护垫，手握把手还是前臂推垫没有核实，说明按“前臂贴垫、手握上方把手”写。
- **分辨率不一致**：16 个动作的动作图是 627×627，其余是 768×768。涉及 ex-0022、ex-0105、ex-0111、ex-0299、ex-1160、ex-1201、ex-1316、ex-1471、ex-2136、ex-2798、ex-3145、ex-3214、ex-3215、ex-3224、ex-3305、ex-3543。
- **不同动作共用同一组图**：ex-0022 与 ex-1316、ex-0029 与 ex-0039、ex-0057 与 ex-0061、ex-0213 与 ex-2616、ex-0315 与 ex-0317、ex-0472 与 ex-1764、ex-1511 与 ex-1576、ex-1649 与 ex-1652。
- **背景内框**：ex-0308 的两张图背景里能看到一圈颜色略浅的矩形边界。其他图片没有逐张检查，可能还有同类情况。
- **多数动作只有开始和结束两帧**：1,268 个动作没有中间阶段图，动作路径需要结合文字理解。
- **只公开了生成模型**：图片使用 OpenAI 的 GPT Image 2 生成，提示词和筛选过程没有公开。

## 文字

- **388 条中文说明在 0.3.0 由 AI 重写**：0.2.0-rc.1 里有 326 条说明只有一句画面描述，另有 62 条是画面描述或混着图片审核备注。这些说明已按原描述所记录的动作变式改写成分步说明，但改写时没有逐张重新看图，也没有人工逐条核对。
- **447 条英文说明在 0.3.0 新增**，由 AI 按中文步骤翻译，没有人工核对。
- **约 210 条说明保留上游机器翻译的语气**，例如“启动你的核心”“将肩胛骨挤压在一起”，意思可以理解，但不够自然。
- **36 个名称带“（版本2）”“（变式2）”一类后缀**：它们对应上游的 `v. 2`、`v. 3` 或重名条目，上游没有说明版本之间的差别，这里也没有补充。
- **部分名称保留上游的示范说明**，例如“（男性）”“（背面视角）”“（空杆示范）”。

## 数据

- **没有次要肌群、难度和动作类别字段**。上游有次要肌群数据，但用词不统一，暂未收录。
- **`target` 是英文键**，中文名称在 `target_zh`。
- **上游英文原名里的乱码已修正**：上游把 `45°` 写成了 `45в°`，本数据集的 `source.name` 改回 `45°`，与上游文件逐字比较时会有 4 处不同（ex-0738、ex-0739、ex-0740、ex-1464）。
- **少数记录的分类与上游不同**，是按图片内容调整的：例如 ex-3119 上游归在腰腹、目标为腹肌，这里归在臀腿、目标为臀肌；ex-0020 图中使用平衡板，器械记为平衡板而不是自重。
- **动作编号不连续**：编号沿用上游，上游 1,324 条里有 28 条没有收录。
